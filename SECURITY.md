# Security

Please report security-relevant issues privately to the author via e-mail.
The address is in the sources. You may ask for a public GPG key if you'd prefer encrypted communication. (In that case, remember to include *your* public key, too.)

We **do not** accept incoming reports through GitHub's Security advisories panel.

Do not use the project's public issue board for security issues.
Do not disclose your issue to the public. That is to say, give us a fair amount of time to respond before you do (like between 30 and 90 days).
Once contact has been established, wait patiently until the issue has been fully understood and a proper fix is available. Remember, no cure worse than the disease.
Coordinate disclosure with the project owner. Please do not unilaterally disclose your issue without consent.

This security policy goes for all pypdfium2-team subprojects including `pypdfium2`, `ctypesgen` and `gn-dist`.
