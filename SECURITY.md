# Security

Please report security-relevant issues privately to the author via e-mail.
The address is in the sources. You may ask for a public GPG key if you'd prefer encrypted communication.[^1]
We do not accept incoming reports through GitHub's Security advisories panel.

Make sure your submission is in line with our [No AI policy](https://github.com/pypdfium2-team/pypdfium2/blob/f0f691d21bdeb75a367171e7279b72e152561ad9/README.md#no-ai-issues-and-prs).
That is, only purely human-written issue reports are accepted. AI(-'assisted') slop is prohibited and will be considered spam.
It does not matter whatever tools you may have used to *discover* the issue, but your report and any code therein must be exclusively human, written from scratch without the influence of chatbots/LLMs.

Do not use the project's public issue board for security issues.
Give us a fair amount of time (30+ days) for an initial response before disclosing your issue in any way.
Once contact has been established, be patient and wait until the issue has been fully understood and a proper fix is available. Await the project owner's consent before disclosing the issue.
Bear in mind that no cure should be worse than the disease, and that this is a volunteer open-source project without support or warranty. Check the project's license for more information.

This security policy goes for all pypdfium2-team subprojects including `pypdfium2`, `ctypesgen` and `gn-dist`.

[^1]: Remember to include your own public key with the request.
